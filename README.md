# Vaelon Characters

Character sheets for the Castoria campaign: Alden Vaelon III (Life Cleric 4) and Lady Elyndra Vaelon (Inquisitive Rogue 4). Single-file PWA on GitHub Pages; each character's state saves on the device and syncs via Firebase Realtime Database (project aldenvaelon-bac1e).
